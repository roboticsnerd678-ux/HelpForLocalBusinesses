Project Title & Description:
The “That’s Near Me?!” application specifically offered in Phoenix serves to expand the limited reach that local businesses have in Phoenix, Arizona. Whether a small business just started or they have cemented a legacy, the impact they bring to the community cannot be overstated. As Business.com puts it like this:
“Small businesses employ local residents, directly returning some of the money they generate to community members. Additionally, small businesses often support other local small businesses as customers or suppliers. For example, a chef at a local restaurant might stop by the neighborhood farmers’ market to purchase fresh, homegrown produce for weekly specials and menu items.” (1)
For reasons like these, we must ignite communities including people looking to support a small business or small business looking to support people. In its beta stages, this service offers business owners to showcase their local business and offers information on local businesses for the general public.

Installation:
As this is only in the Beta stages, the program and database is all in a folder called HelpForLocalBusinesses available at this Github Repo - https://github.com/roboticsnerd678-ux/HelpForLocalBusinesses
By using an IDE that is able to run Python (VS Code Recommended), you should be able to clone the repo above and run main.py to see its function. 
Just make sure Python is installed - https://www.python.org/downloads/
Install Dependencies: Install the required Pillow library.
bash
pip install Pillow
	Usage:
The Usage is pretty self explanatory from the UI hints scattered across the application. The only extra bit of information is the ability to add huge data sets by editing the businesses.json file. 
The main language was python and the UI was made possible by pythons built it Tkinter library. The ability to import png’s was thanks to the PIL library (otherwise known as Pillow.
